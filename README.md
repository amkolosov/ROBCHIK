# ROBCHIK
Проект, созданный по заданию Конкурса "Код Атома 2026". 
Разработана модель устройства для автоматизации производственного процесса на АЭС.
Функция автономного робота - заменить работу обходчика турбинного оборудования на атомной станции.
Проводить регулярный мониторинг за прикреплёнными объектами, регистрировать состояние, реагировать на отклонения в работе, прогнозировать ситуацию с оборудованием на будущее.
